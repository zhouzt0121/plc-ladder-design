# 步序模板参考

把「步序数据」批量渲染成 LAD 网络。模板来自 `ladfc.py` 构件，下面是直接可用的伪代码与语义。

## 先定：用模板 A 还是模板 C？

判断「动作是条件的后果」还是「动作是步指令」：

| 模板 | 适用 | 结构 | 例子 |
|---|---|---|---|
| **A 条件后果** | 动作由传感器触发、到位即执行 | `STEP[n] → 条件 → 动作`，推进另起支路 | 第二站原程序「到位即停电机」 |
| **C 入口动作** | 动作是步指令，进本步就发出，然后等反馈 | `STEP[n] → 运行闸门 → 动作`；`闸门 → 条件 → 清步置步` | 顺序控制新站「置位定位、置位夹紧」 |

**顺序控制流程图的动作默认是模板 C**（IFAE/GPP/SFC/手绘/表格描述都按此判断）。混用 A/C 会死锁（步1「置位上料电机使能」串在「上料点有料」后 → 电机不转 → 永远没料 → 永远等不到；步3「气爪夹紧指令」串在「气爪夹紧」后 → 不发夹紧指令 → 永远等不到）。

## 标准步（模板 C，`step`）

```python
step(f, f.net("步N：标题", "注释"),
     idx,          # 步号（对应 STEP[idx]）
     conds,        # 转移条件列表，前缀 '!' 表示常闭触点，如 ["移动完成", "!对射光纤"]
     actions,      # 入口动作（lambda: SET(…) / RST(…)），必须非空；纯延时步给保持性动作
     nxt,          # 目标步；缺省 idx+1；末步回初始步传 nxt=0
     run=运行中, start=启动, step0=S0,
     ton=None)     # 延时步给 (实例, 'T#2s')
```

生成的三层节点：
- `cNa = STEP[n]`（动作源）
- `cNb = STEP[n] AND (自动运行中 OR 启动)`（动作执行 + 转移起点）
- `cNc = cNb AND 转移条件 [AND TON]`（清 `STEP[n]` + 置 `STEP[nxt]`）

**`nxt` 缺省是 `idx+1`；末步回环必须显式 `nxt=0`，不要写 `idx+1`（会多置一个永不使用的 STEP）。**

## 初始步（`step0` / `step0_and`）

- `step0_and(f, n, conds, step0, nxt=1)`：全部初始条件**串联与逻辑** + `STEP[0]`。不加运行闸门——`STEP[0]` 本身只在启动时置位、停止时清除，已是启动标志。
- `step0(f, n, conds, actions, run, start, step0, nxt=1)`：加运行闸门，但**不清除 `STEP[0]`**（循环入口常驻）。

**`STEP[0]` 常驻的副作用**：初始条件再次满足时，步1 会被提前置位、与 `STEP[10]/[11]` 重叠一个扫描周期。实际无害（有料时立即接续下一轮，无料时 `STEP[11]` 稳定呈现并停电机等待）。

## 选择序列（`step_branch`）

一个网络内挂多条出口，互斥双支汇到各自 `STEP`：

```python
step_branch(f, n,
    idx,
    actions,                      # 入口动作（一次）
    branches,                     # [(条件列表, 目标步), …]
    run=运行中, start=启动, step0=S0)
```

例（步3 按对射光纤 B4 判定分流）：

```python
step_branch(f, f.net("步3：…", "…"), 3,
    [lambda: SET(转120)],
    [([移动完成, 方向旋转有料, 对射光纤], 4),      # 需要调整 → 步4a
     ([移动完成, 方向旋转有料, "!"+对射光纤], 13)],  # 不需调整 → 步4b（跳号）
    run=运行中, start=启动, step0=S0)
```

`I_Contact(标志)` 与 `Contact(标志)` 形成互斥双支；各支的 `S_Coil(STEP[n+1])` 写在不同 rung = 天然或逻辑。跳号（4→13）表示「不需调整」支路跳过中间方向调整步。

## 双线圈气缸复位（硬约束）

双线圈气缸（伸出/缩回两个独立输出）复位时**必须主动 S 回位线圈**，不能两个都 R（同时失电机械上不安全）：

```python
actions = [lambda: SET(推料气缸缩回), lambda: RST(推料气缸伸出)]  # 伸→缩
```

## 脉冲闸门版（`step_p` / `step0_p` / `step_branch_p`）

手动模式要求「按一次启动走一步」，且 `P_Contact` 正跳变触点每周期刷新边沿存储位、**严禁多网络共用同一 bit**（第一个网络消费上升沿后其余永不动作）。正确做法：

1. 在「开车与停车」内用 `pulse_net(f, start, edge, pulse)` 只做**一次**边沿检测，产生单周期脉冲位 `pulse`。
2. 全部步序网络改用 `step_p`（把 `启动` 电平触点换成 `pulse` 脉冲位），手动单步时脉冲通一个周期完成转移。

```python
kw = dict(run=运行中, start=启动, edge=edge, step0=S0)   # edge/pulse 是 DB 成员
step_p(f, f.net("步1", "…"), 1, [移动完成, 方向检测有料],
       [lambda: SET(转60)], nxt=2, **kw)
```

`step_p` 里定时器由 `STEP[n]` 直接驱动（不挂闸门），手动模式不需按住等延时。

## 步序数据长这样（抽数据产物）

```
步0 → 初始条件[上料有料, 升降抬起, …] → 步1
步1 → 动作[SET 转60度]  条件[移动完成, 方向检测有料]  → 步2
步2 → 动作[RST 转60度]  条件[延时 T#1s]              → 步3
步3 → 动作[SET 转120度] 分支{ 条件[移动完成,有料,对射光纤]→步4 ; 条件[移动完成,有料,!对射光纤]→步13 }
…
末步 → nxt=0 回初始步
```
